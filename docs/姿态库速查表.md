## 在 MuJoCo 中查看

运行下列命令，窗口会循环播放上表中的看向、倾听、点头、好奇、摇头与阅读姿态：

```powershell
.\.venv-mujoco\Scripts\python.exe simulate_mujoco_trained_policy.py
```

姿态的唯一代码源是 `lamp_core/pose_library.py`；动作组合在 `lamp_core/action_motion.py`。每次新增姿态，`simulate_mujoco_pose_training.py` 都会自动扩展成所有有向转场并验证训练回放。
