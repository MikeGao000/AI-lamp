# 新电脑（Windows）开发环境配置

用于公司 / 家里交替开发：代码靠 GitHub `develop` 同步，每台电脑各自配置一次。
本页只覆盖 Windows 开发机；树莓派见 [树莓派安全模拟部署.md](树莓派安全模拟部署.md)。

## 给新电脑上的 Claude 的一句话

在新电脑的 Claude 桌面应用（Code 标签页）里，打开 `C:\Users\<你>\Projects`，发：

> 克隆 https://github.com/MikeGao000/AI-lamp.git 并切到 develop，然后按仓库里 docs/新电脑配置.md 把这台电脑配好，最后跑单元测试。

## 步骤

1. **Python 3.12**（用户级，不需要管理员）：
   `winget install --id Python.Python.3.12 -e --scope user --source winget`
   装完要**新开终端**。Windows 上用 `python` / `py`，不要用 `python3`（会跳到微软商店）。
2. **依赖**：`python -m pip install numpy opencv-python`
   （Pi 上的 OpenCV 用 apt 装，版本可能不同，Windows 上测试通过不代表 Pi 行为一致。）
3. **控制台编码**：`setx PYTHONIOENCODING utf-8`，否则中文 Windows 的 GBK 控制台会让 `test_page_memory` 报 `UnicodeEncodeError`。
4. **.env**：`copy .env.example .env`。模板里全是代码默认值，云功能关闭，不需要任何密钥就能写代码、跑测试和仿真。
   要用云端识图 / TTS 时，**自己**在 `.env` 里填 `OPENAI_API_KEY` 并改 `ENABLE_CLOUD_VISION=true`；
   密钥从服务商控制台（OpenAI / DeepSeek）重新生成或从密码管理器复制，不要发给 Claude、不要提交。
   如果另一台电脑的 `.env` 改过非密钥项（如 `OPENAI_BASE_URL`、`VLM_MODEL`、语言），这里也要同样改。
5. **验证**：`python -m unittest discover -s tests`，应全部通过。
6. **远程控制**：在会话输入框里输入 `/remote-control`；设置 > Code 里可打开“新会话默认连 Remote Control”。
   电脑不能睡眠（设置 > 系统 > 电源和睡眠）。

## 每天怎么同步

仓库自带 `.claude/hooks`：开新会话时自动把 develop 快进到最新；有未提交或未推送的工作时提醒。
收工前对 Claude 说“提交并推送”，没做完就推到 `wip/<名字>` 分支。
