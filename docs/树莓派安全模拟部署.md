# 树莓派安全模拟部署

目标：在 **不接 MKS、不接 CAN HAT、不接 24 V 电机电源** 的条件下，在 Raspberry Pi 上确认 Python、项目代码、相机、静止检测与 TTS 能运行。此流程只使用 `VirtualMotorBus`，不会输出真实电机命令。

## 0. 准备条件

- Raspberry Pi OS 64-bit（建议 Bookworm）已能联网。
- 已启用 SSH；推荐在电脑上通过 SSH 操作。
- Pi Camera Module 3 已接好；相机测试命令 `rpicam-hello -t 0` 能显示预览。
- 第一轮**不要**把 CAN HAT、MKS、24 V 电源接进测试范围。

## 1. 将项目复制到树莓派

可用 Git、U 盘或电脑的 SFTP/WinSCP 复制整个 `智能台灯` 文件夹。假设复制后路径为 `~/smart-lamp`：

```bash
cd ~/smart-lamp
python3 --version
python3 -m unittest discover -s tests -v
python3 app_main.py --mode simulate
```

预期：31 个离线测试通过；主程序打印虚拟总线和语音日志。此时未使用相机、GPIO、SPI、CAN 或串口。

## 2. 安装 Pi 相机与语音演示依赖

```bash
sudo apt update
sudo apt install -y python3-picamera2 python3-opencv espeak-ng
cd ~/smart-lamp
cp .env.example .env
python3 app_main.py --mode pi
```

预期：终端显示 `Camera loop started. Motors remain virtual...`。把一本书放入镜头、保持静止，程序才会触发一次模拟阅读流程。用 `Ctrl+C` 停止；这会进入软件急停状态，但没有真实电机可停。

若没有相机，先只运行第 1 节；不要为了跳过错误而修改电机相关代码。

## 3. 可选：启用云端页面理解

只有你主动希望让稳定书页发送给云端模型时，才编辑 `.env`：

```ini
ENABLE_CLOUD_VISION=true
OPENAI_API_KEY=你的密钥
```

- `.env` 已被忽略，不能提交或发送给他人。
- 每次只上传一张通过静止门的 JPEG；没有配置密钥时是完全离线模拟。
- 云端回复仍只会传给虚拟电机总线，绝不会输出 CAN。

## 4. USB 麦克风：单独验证，不与电机测试混合

接入 USB UAC 麦克风后：

```bash
arecord -l
arecord -D default -f S16_LE -r 16000 -c 1 -d 5 mic-test.wav
aplay mic-test.wav
```

确认录音清晰后，才安装 Vosk/`sounddevice` 并接入连续语音流。第一版采用半双工：TTS 播放时暂停识别。

## 5. 此阶段的通过标准

- 离线测试全部通过。
- `app_main.py --mode simulate` 正常结束。
- 有相机时，静止书本只触发一次流程，不因微小画面噪声反复触发。
- `espeak-ng` 可从扬声器输出；可选 USB 麦克风可录回放。
- 证明终端中没有 CAN、`/dev/tty*` 或 GPIO 电机访问。

## 6. 之后才进入单轴 MKS 测试

真实电机阶段必须另开检查表：确认 MKS SERVO42D CAN 的准确版本/手册，安装 CAN HAT，验证终端电阻和单轴心跳，接 NC 限位与硬件急停，最后才以无负载低速运动。当前项目故意没有真实 CAN 帧驱动，不会假装可直接上电。
