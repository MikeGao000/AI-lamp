# 检测异步化优化与验证

本轮把交接包的新检测模块与本地已有改动保留在 develop；未修改 main 分支，未启动电机或云 API 实测。

## 已修正

- 预览检测结果超过 1.5 秒不再用于跟踪；检测异常清除旧结果。
- 检测线程使用独立图像副本，防止预览标注污染 OCR 与模型输入。
- 显著检测进程携带拍摄时间，超过 8 秒的结果丢弃；空结果和错误清除旧框，缓存最长保留 8 秒。
- 重置与检测串行化，防止上一轮检测在重置后写回旧框。
- 关闭预览时等待检测线程并停止显著检测子进程；停止后的子进程不允许重新启动。
- 搜索不再擅自把配置转速提升到 120 RPM，保留用户设置的运动上限。
- 本地 CRNN 分行裁剪改为包含文字行，而不是文字行之间的空白。

## 验证范围与限制

运行 tests 的离线 unittest 回归，并新增检测时效、输入副本、显著框失效和 OCR 裁剪测试。
这只能证明软件回归，不能证明真机跟随更丝滑。下一轮须以受限运动范围分别测量检测延迟、丢框重获时间、中心误差和反向次数。

显著检测本身不是书本分类器；当前模型仍需约五秒。缓存失效后暂时交给实时跟踪或搜索，不把历史显著框当成持续确认。后续可将采样时的电机位置纳入结果，或者只在轴稳定时接受显著框。

模型权重、照片、音频、密钥与本机运行产物不上传；部署机器须另行准备模型权重。
